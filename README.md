# Customer Churn & Retention Analysis Dashboard (Power BI)

## 📌 Project Overview
This project analyzes customer churn behavior and retention trends using Power BI.

## 📊 Key KPIs
- Total Customers
- Churned Customers
- Churn Rate (%)
- Retention Rate (%)
- Active Customers

## 📈 Dashboard Features
- Churn trend analysis
- Customer segmentation
- Interactive slicers
- Clean & professional layout

## 🛠 Tools Used
- Power BI
- DAX
- Excel / CSV Dataset
